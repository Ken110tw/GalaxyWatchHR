# ♥ Galaxy Watch 區網即時心率懸浮視窗 (GalaxyWatchHR)

**[繁體中文](README.md) | [English](README.en.md)**

一套**純區域網路、零外部雲端、無廣告、超低延遲**的即時心率顯示工具。將 Samsung Galaxy Watch（Wear OS 3 / 4 / 5 / 6，已實測 Galaxy Watch 9）的心率直接透過 Wi-Fi 區網傳送到 Windows 電腦，以**透明背景、可隨時拖曳、隨 BPM 同步跳動**的懸浮小視窗顯示於螢幕最上層。

---

## 核心特色

- **純區網直連（UDP Port `19888`）**：不經第三方伺服器、不需註冊帳號、延遲極低（< 5ms）。
- **單一獨立執行檔，免裝環境、免開終端機**：
  - 只要下載單一 `GalaxyWatchHR.exe` 就能直接在任何 Windows 10/11 電腦執行。
  - **內建圖形化「手錶安裝與防火牆精靈」**：內嵌輕量手錶 APK（~29 KB），若電腦沒有 `adb` 會詢問並自動下載 Google 官方 Platform-Tools，一鍵完成防火牆放行、無線側載安裝與背景權限授權！
- **透明動畫懸浮視窗**：
  - 真透明背景 + 高對比文字陰影，深色遊戲與淺色網頁都清晰可讀。
  - 雙重跳動（lub-dub）愛心與擴散光環動畫，**節奏即時同步實際心率 BPM**。
  - 支援滑鼠左鍵隨時拖曳並記憶位置、`Ctrl + 滾輪` 縮放、鎖定位置、**滑鼠穿透模式**（遊戲不擋點擊）、**開機自動啟動**。
- **手錶端穩定背景運行**：
  - 完整支援 Wear OS 4 / 5 / 6 背景心率權限（`BODY_SENSORS_BACKGROUND`、`READ_HEART_RATE`、`READ_HEALTH_DATA_IN_BACKGROUND`、`FOREGROUND_SERVICE_HEALTH`），回到錶面或熄屏皆持續傳送。
  - 內建 **12 秒光學晃動防抖緩衝**：手腕短暫移動造成感測器瞬間讀不到時，平滑保留有效數值不閃爍。
- **中英文雙語介面**：電腦端與手錶端皆自動偵測系統語系，並可隨時一鍵手動切換繁體中文 / English。

## 快速開始（完全免終端機，3 步驟完成）

### 步驟 1：下載並啟動電腦端程式
1. 從本專案的 **Releases** 頁面下載 **`GalaxyWatchHR.exe`**（單一檔案，無須解壓縮或安裝 .NET）。
2. 將 `GalaxyWatchHR.exe` 放在你喜歡的位置（例如桌面），**雙擊啟動**。
3. 螢幕左上角會出現透明心率懸浮視窗（待機中會顯示你電腦的區網 IP），Windows 右下角系統匣也會出現一顆紅愛心圖示。

### 步驟 2：開啟內建「手錶安裝與防火牆精靈」
對透明心率視窗（或右下角系統匣紅愛心圖示）按**滑鼠右鍵** → 選擇 **「手錶安裝與防火牆精靈...」**：

1. **一鍵放行防火牆**：
   - 點擊卡片 1 的 **「一鍵放行防火牆」**，在 Windows 系統管理員視窗點「是」，即可自動放行同區網 UDP `19888`（無論你的 Wi-Fi 被 Windows 設為私人或公用網路都能正常接收）。
2. **在 Galaxy Watch 開啟無線偵錯**：
   - 確認手錶與電腦連在**同一個 Wi-Fi 路由器**。
   - 手錶進入：**設定 → 關於手錶 → 軟體資訊 → 連點「軟體版本」7 次**（直到提示已開啟開發人員模式）。
   - 返回設定最下方，進入 **開發人員選項** → 開啟 **ADB 偵錯** 與 **無線偵錯**。
3. **填寫位址並一鍵安裝**：
   - **首次安裝此電腦**：勾選「首次連線此電腦（需要輸入配對碼）」，在手錶點 **「使用配對碼配對新裝置」**，將畫面上顯示的 **配對 `IP:Port`** 與 **6 位數配對碼** 填入精靈中。
   - 返回手錶「無線偵錯」主畫面，查看最上方的 **「IP 位址與通訊埠」**（注意：此處 Port 與剛才配對畫面不同），填入精靈的 **「無線偵錯主畫面 IP:Port」**。
   - 點擊 **「一鍵安裝並自動開啟背景權限」**：
     - 若電腦尚未安裝 `adb`，精靈會詢問是否自動從 Google 官方下載輕量 Platform-Tools（約 6 MB），點「是」即可自動完成。
     - 安裝完畢後會自動幫你授予所有背景心率權限、加入省電白名單，並在手錶上自動開啟「區網心率」App！

### 步驟 3：開始即時同步心率
1. 在手錶的 **「區網心率」** 畫面點一下 **「開始傳輸」**。
   - App 會自動在區網內搜尋電腦並開始即時顯示心率。
   - 若你的分享器阻擋區網廣播封包，請在手錶「電腦 IP」欄位直接輸入精靈顯示的電腦 IP（例如 `192.168.1.100`，支援 `.` 輸入）再按開始即可。
2. 連線成功後即可按 **Home 鍵回到錶面或讓螢幕熄滅**，心率會在背景持續更新！
3. **建議**：安裝完成後回到手錶「開發人員選項」，將 **「無線偵錯」關閉** 以節省電力。

## 常見問題排錯（FAQ）

1. **手錶一直顯示「搜尋區網電腦中...」或電腦收不到心率？**
   - 確認已在精靈中點擊 **「一鍵放行防火牆」**（顯示綠色「已放行 UDP 19888」）。
   - 確認手錶與電腦連在**同一個 Wi-Fi 路由器網段**（例如同為 `192.168.x.x`）。
   - 部分路由器預設過濾廣播封包，請在手錶 App 的「電腦 IP」欄**直接手動輸入電腦區網 IP**。
2. **打遊戲時看不到透明心率視窗？**
   - Windows 原生置頂視窗無法覆蓋「獨佔全螢幕（Exclusive Fullscreen）」模式。請將遊戲顯示設定改為 **「無邊框視窗化（Borderless Windowed）」**，並開啟「滑鼠穿透模式」即可完美覆蓋且不擋滑鼠點擊。
3. **手錶心率偶爾會停住幾秒或變 `--`？**
   - 手腕劇烈移動時光學感測器可能短暫失準；本程式已內建 **12 秒防抖緩衝**。若經常出現，建議將錶帶稍微戴貼合手腕（離腕骨約一指寬）。
4. **把 `GalaxyWatchHR.exe` 移到別的資料夾後，開機沒有自動啟動？**
   - 移動檔案後，請對懸浮視窗按右鍵，把「開機自動啟動」取消勾選再重新勾選一次，即可更新新的執行檔路徑。

### 自行編譯需求與指令
- **手錶 APK**（需 Java JDK 17/20 與 Android SDK `android-34` + `build-tools 33.0.2`，免 Gradle、全離線編譯）：
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\watch-app\build_apk.ps1
  ```
  產出檔案位於 `dist\GalaxyWatchHR.apk`。
- **Windows 單一獨立執行檔**（需 .NET 7 SDK，會自動將 `dist\GalaxyWatchHR.apk` 內嵌進 `.exe`）：
  ```powershell
  dotnet publish .\pc-overlay\WatchHROverlay.csproj -c Release -r win-x64 --self-contained true -o .\release
  ```
  產出檔案位於 `release\GalaxyWatchHR.exe`。
